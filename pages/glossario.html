Glossário

Termos que aparecem nas entrevistas, em ordem alfabética. Use o filtro.

TermoDefinição
ACIDAtomicidade, Consistência, Isolamento, Durabilidade: garantias de transações em bancos relacionais.
Adaptive bitrate (ABR)Streaming em segmentos com várias qualidades; o player troca conforme a banda (HLS, DASH).
Anti-entropyProcesso de background que sincroniza réplicas divergentes (geralmente com Merkle trees).
API gatewayPorta de entrada única: autenticação, rate limiting, roteamento, métricas.
At-least-once / at-most-once / exactly-onceSemânticas de entrega: pode duplicar / pode perder / nem um nem outro (na prática: at-least-once + idempotência).
BackpressureMecanismo para o consumidor sinalizar ao produtor que desacelere.
Base62Codificação com [0-9a-zA-Z]; usada em códigos curtos.
Bloom filterEstrutura probabilística: "certamente não está" ou "talvez esteja".
CAPDurante uma partição de rede, escolha entre consistência e disponibilidade.
Cache-asideA aplicação lê do cache; num miss, lê do banco e popula o cache.
CDC (Change Data Capture)Capturar mudanças do banco (pelo log de replicação) e publicá-las como eventos (Debezium).
CDNRede de servidores de borda que cacheia conteúdo perto dos usuários.
Circuit breakerInterrompe chamadas a uma dependência que está falhando, falhando rápido.
Consistent hashingMapeia chaves e nós num anel; mudar nós move ~1/N das chaves.
Count-Min SketchEstrutura probabilística para contar frequências com memória fixa (superestima).
CQRSSeparar o modelo de escrita do modelo de leitura.
CRDTTipos de dados que convergem automaticamente sem coordenação.
DAGGrafo acíclico direcionado; usado para pipelines de tarefas com dependências.
DAU / MAUUsuários ativos diários / mensais.
Dead-letter queue (DLQ)Fila para mensagens que falharam repetidamente.
Delta syncSincronizar só as partes (blocos) alteradas de um arquivo.
DenormalizaçãoDuplicar dados para evitar joins e acelerar leituras.
Event sourcingEstado derivado de um log imutável de eventos.
Eventual consistencySem novas escritas, as réplicas convergem com o tempo.
FailoverTroca automática para um componente reserva quando o principal falha.
Fanout on write / on readDistribuir o conteúdo na escrita (push) ou montar na leitura (pull).
Fencing tokenNúmero crescente associado a um lease; o storage rejeita tokens antigos.
GeohashCodifica latitude/longitude numa string; prefixos comuns indicam proximidade.
GeoDNSDNS que responde com IPs diferentes conforme a localização do cliente.
GossipProtocolo em que nós trocam estado com vizinhos aleatórios; a informação se espalha em O(log N).
GOPGroup of Pictures: bloco de quadros de vídeo que pode ser decodificado independentemente.
gRPCRPC sobre HTTP/2 com Protocol Buffers.
Hinted handoffOutro nó guarda escritas de uma réplica fora do ar e as entrega quando ela volta.
Hot key / hotspotChave ou partição que recebe tráfego desproporcional.
HyperLogLogEstrutura para contar elementos distintos aproximadamente com poucos KB.
IdempotênciaRepetir a operação tem o mesmo efeito que executá-la uma vez.
JitterAleatoriedade adicionada a intervalos (retries, TTL) para evitar sincronização.
Leaky / leaking bucketRate limiting com fila de tamanho fixo processada a taxa constante.
LeasePermissão com prazo (por exemplo, liderança) que precisa ser renovada.
LinearizabilidadeConsistência mais forte: o sistema se comporta como uma única cópia.
Load sheddingRejeitar tráfego quando sobrecarregado para evitar colapso.
Long pollingCliente segura a requisição aberta até haver novidade ou timeout.
LSM treeEstrutura de storage com memtable + SSTables imutáveis + compaction; escrita rápida.
Merkle treeÁrvore de hashes para comparar grandes conjuntos de dados eficientemente.
Multipart uploadUpload de arquivo grande em partes paralelas e retomáveis.
OutboxTabela de eventos gravada na mesma transação dos dados, publicada depois.
p99Percentil 99: 99% das requisições são mais rápidas que esse valor.
PACELCExtensão do CAP: sem partição, troca entre latência e consistência.
Presigned URLURL temporária assinada que permite upload/download direto no object storage.
QuadtreeÁrvore que divide o espaço 2D em quadrantes, adaptando-se à densidade.
Quórum (N, W, R)Réplicas, confirmações de escrita e de leitura; W+R>N garante sobreposição.
Raft / PaxosAlgoritmos de consenso; toleram f falhas com 2f+1 nós.
Rate limitingLimitar requisições por cliente num intervalo.
Read repairNa leitura, atualizar réplicas que tinham versões antigas.
Replication lagAtraso entre a escrita no primário e sua chegada às réplicas.
SagaSequência de transações locais com ações compensatórias.
ShardingDividir dados entre bancos com o mesmo esquema.
SLA / SLO / SLIAcordo com o cliente / meta interna / métrica medida.
Sloppy quorumQuórum que aceita nós saudáveis fora da lista preferencial.
SnowflakeGerador de IDs de 64 bits: timestamp + datacenter + máquina + sequência.
SPOFSingle point of failure: ponto único de falha.
SSEServer-Sent Events: stream unidirecional servidor → cliente sobre HTTP.
SSTableSorted String Table: arquivo imutável ordenado por chave.
StatelessServidor que não guarda estado de sessão entre requisições.
Sticky sessionLB envia sempre o mesmo cliente ao mesmo servidor.
Thundering herdMuitas requisições simultâneas a um recurso (por exemplo, quando um cache expira).
Token bucketRate limiting com balde de tokens reposto a taxa fixa; permite rajadas.
TrieÁrvore de prefixos; base do autocomplete.
TTLTime to live: prazo de validade de um dado em cache.
Vector clockLista de contadores por nó que detecta escritas concorrentes.
VnodeNó virtual: várias posições de um servidor no anel de hash.
WatermarkEm stream processing, estimativa de "até que tempo os eventos já chegaram".
WebSocketConexão bidirecional persistente sobre TCP, iniciada via HTTP.
Write-behind / write-throughCache grava no banco depois (assíncrono) / junto (síncrono).
